# LedgerLab requests

1. Start LedgerLab locally so it listens on `http://127.0.0.1:8000`.
2. Run `resterm` in this directory.
3. Place the cursor inside a request in `requests.http` and press Ctrl+Enter.
4. Use `resterm.env.json` to change the base URL when needed.

Each current LedgerLab endpoint has one request.
